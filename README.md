# 胖东来 · 顾客反馈分类与优先级助手

面向胖东来客服场景的 AI 应用 demo：输入顾客反馈文本，自动输出「分类 + 情绪 + 优先级 + 建议处理动作」的结构化结果，用于客服工单的自动分流与质检。

## 为什么做这个

胖东来以极致服务著称，顾客反馈是核心资产。海量反馈如果靠人工逐条分类、定优先级，效率低且口径不一。这个 demo 演示的是：如何用「规则基线 + 大模型增强」的架构，把反馈处理变成可复用、可评测的工具。

## 功能

- **六类自动分类**：商品质量 / 服务态度 / 价格 / 卫生 / 商品缺货 / 其他
- **情绪识别**：正面 / 中性 / 负面
- **优先级判定**：负面且涉及商品质量/卫生 → 高；其他负面 → 中；正面/建议 → 低
- **建议处理动作**：按「分类 × 情绪」生成差异化的处理建议
- **双模式运行**：
  - **规则兜底**（默认，零依赖）：关键词 + 情绪词匹配，任何环境都能跑
  - **大模型增强**（配置 API key 后）：Prompt 工程 + 结构化 JSON 输出，理解更准、可迁移到冷门表达

## 运行

```bash
# 规则兜底（无需任何配置）
python feedback_classifier.py

# 大模型增强（OpenAI 兼容接口，默认 DeepSeek）
$env:DEEPSEEK_API_KEY = "你的key"
python feedback_classifier.py
```

可选参数：`--input`（反馈文件，每行一条，`#` 开头忽略）、`--base-url`、`--model`。

## 输出

> 完整结果见 `output/反馈分类结果_2026-10-17.md` 与同目录 `.json`（结构化 JSON），摘要：

| 优先级 | 分类 | 情绪 | 顾客反馈 | 建议动作 |
|---|---|---|---|---|
| 高 | 商品质量 | 负面 | 水果不新鲜，芒果有发霉 | 立即核实，必要时下架或抽检 |
| 高 | 卫生 | 负面 | 卫生间有异味 | 当天安排卫生整改/消杀 |
| 中 | 商品缺货 | 负面 | 面包连续三次没买到 | 转补货，反馈到货时间 |

## 技术栈

Python（标准库 urllib，零第三方依赖）· 规则引擎（关键词 + 情绪词典）· 大模型 API（OpenAI 兼容，Prompt 工程 + JSON 结构化输出）

## 对应岗位职责

- **大模型应用**：模型 API 接入、Prompt 优化、`response_format` 结构化输出
- **知识库与评测**：分类体系与关键词词典的可配置、结果可评测、内容可追溯
- **生产落地**：大模型调用失败时自动降级为规则兜底，保证服务可用性
